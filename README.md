# QR-3D

This was all vibe coded

## What is this

Needed something that could generate QR codes locally fast and easy and allow for exporting to `.stl` and `.obj` files for printing. Just asked claude to do the heavy lifting here, as I didn't want to spend much time on this.

## Usage

`just vendor-fetch && just run`

There is an interactive tui made with ncurses to walk you through how to create what you want.
